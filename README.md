# PremierLift CRM

CRM лифтовой сервисной компании: диспетчерская, реестр объектов и лифтов, клиенты и договоры, обслуживание, отчёты и приложение мастера. Python/Flask, SQLAlchemy/SQLite, HTML/JavaScript. Данные хранятся локально в `lift_crm.db`, файлы — в `uploads/`.

## Запуск

```bash
python3 -m venv venv
venv/bin/python -m pip install -r requirements.txt
venv/bin/python app.py
```

Откройте [CRM](http://127.0.0.1:5000). По умолчанию сервер доступен только на этом компьютере, отладчик выключен. Другой порт: `PORT=5001 venv/bin/python app.py`. Файл `.env.example` — справочник переменных; приложение не читает `.env` автоматически.

При первом запросе создаются таблицы и выполняются добавочные миграции. Перед обновлением существующей базы остановите сервер и выполните `venv/bin/python scripts/backup_local.py`. Миграция объектов сохраняет адреса старых заявок и допускает повторный запуск.

В новой локальной базе доступны `admin / admin123`, `dispatcher / disp123`, `master1 / master1123` … `master5 / master5123`. Пароли существующих пользователей при обновлении не заменяются. Управление доступами и смена паролей находятся в разделе «Пользователи и допуск» администратора.

## Что готово

- **Обзор:** активные, срочные, неназначенные и просроченные заявки, выполненные сегодня, очередь внимания, загрузка мастеров, динамика за неделю.
- **Заявки:** поиск по номеру и русскому тексту, фильтры, доска статусов, карточка с комментариями, вложениями, сроками, назначением, отменой и архивом.
- **Объекты и лифты:** объект объединяет лифты, адрес, координаты, клиента и договор. Карточки показывают активные и последние заявки, повторные неисправности и обслуживание. Реестр лифтов поддерживает импорт и экспорт CSV/XLSX.
- **Клиенты, договоры, мастера и ТО:** отдельные разделы, связанные карточки, планы обслуживания и создание заявок по плану.
- **Отчёты:** период, статистика по мастерам, причинам обращений, лифтам, объектам, нарушениям сроков. Общий поиск открывает связанные записи.
- **Мобильное приложение:** собственные заявки, следующий шаг, комментарии, фото, история лифта, сохранение действий без сети и синхронизация. У каждого пользователя свой локальный кеш.

## Приложение мастера

Мастер после входа попадает на `/mobile`. Откройте приложение онлайн один раз перед выездом. Затем сохранённые заявки и очередь доступны даже после перезагрузки без сети. При восстановлении связи открытое приложение отправляет действия и фото. Кнопка «Обновить» запускает синхронизацию вручную.

Маршрут работы: **Назначена → Принята → В работе → Завершена**. В работе можно перейти в ожидание с причиной и вернуться. Для начала работ после принятия нужны геолокация и расстояние до объекта не больше 500 м; сервер проверяет это при синхронизации. Завершение требует причины.

Установка на телефон: защищённый адрес CRM **HTTPS**, затем «Установить» в Chrome/Android или «Поделиться → На экран Домой» на iPhone. Адрес `127.0.0.1` работает только на самом компьютере. На iOS приложение нужно открыть для отправки очереди. Это устанавливаемое веб-приложение, отдельной сборки App Store/APK в репозитории нет.

Ошибки остаются в блоке «Требует внимания». При конфликте версии проверьте заявку у диспетчера; удаление ошибочной цепочки с подтверждением загрузит текущее состояние сервера, после чего действие можно выполнить заново. Фото в очереди сохраняются отдельно. Не сбрасывайте офлайн-данные, пока в очереди есть нужные изменения.

## Разработка и проверка

```bash
venv/bin/python -m pytest -q
npm ci
npm run build:css
```

Готовый CSS и Leaflet включены в репозиторий: Node.js и внешние CDN не требуются для обычного запуска. Карта загружает тайлы OpenStreetMap при наличии сети. После изменения мобильных ресурсов увеличьте версию кеша в `static/sw.js`.

Для демонстрации с вымышленными данными и отдельной временной базой:

```bash
venv/bin/python scripts/preview_crm.py
```

Демонстрация открывается на `http://127.0.0.1:5055`; рабочая база не используется.
