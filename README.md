# ERP_lift_company
# 🚀 Lift CRM

**Lift CRM** — это внутреннее web-приложение для лифтовых сервисных компаний, предназначенное для управления заявками на обслуживание, распределения мастеров, контроля этапов работ, ведения архива и отображения объектов на карте.

Проект разрабатывался как простой, автономный и надёжный инструмент для реальной эксплуатации, без тяжёлых CRM-платформ и внешних зависимостей.

---

## 🧠 Назначение системы

Lift CRM решает следующие проблемы:
- потеря заявок из-за звонков, мессенджеров и Excel;
- отсутствие прозрачного контроля работы мастеров;
- отсутствие истории выполненных работ;
- сложность формирования отчётов и архивов.

Система объединяет все процессы в одном web-интерфейсе.

---

## 👥 Роли пользователей

Admin — полный доступ, управление пользователями, просмотр и скачивание архива  
Dispatcher — создание заявок, назначение мастеров, контроль статусов  
Master — просмотр только своих заявок, изменение статусов выполнения  

---

## 🔄 Основные сценарии работы

- Создание заявки диспетчером  
- Назначение мастера из выпадающего списка  
- Обновление статусов мастером (arrive → IN_PROGRESS, complete → COMPLETED)  
- Удаление заявки с автоматическим архивированием  
- Скачивание архива всех заявок в Excel  
- Просмотр объектов (зданий) на карте  

---

## 🗺 Объекты на карте

- Объекты хранятся в файле `objects/objects.xlsx`
- Каждая строка — один объект
- Объекты отображаются на карте OpenStreetMap
- Используются кликабельные круги (circle markers)
- При клике отображается название объекта
- Файл можно редактировать вручную без перезапуска сервера

Формат файла:

object_name | address | lat | lon

Пример:
Central Almaty | Almaty center | 43.238949 | 76.889709

---

## 📦 Архив заявок

- Архив формируется в файле `archive.xlsx`
- Скачивание архива доступно по кнопке в интерфейсе
- Архив содержит ВСЕ заявки, отображаемые во вкладке «Заявки»
- Формат всегда `.xlsx`
- Совместим с Microsoft Excel, Google Sheets и LibreOffice

## 🚀 Установка и запуск (локально)

1. Подготовить окружение  
Python 3.11+ и `pip` должны быть установлены. Рекомендуется использовать виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установить зависимости  
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

3. Запустить сервер разработки  
```bash
python app.py
```

4. Открыть приложение  
Перейдите в браузере по адресу http://127.0.0.1:5000

### Полезные заметки
- При первом запуске автоматически создаются БД `lift_crm.db`, директория `uploads/` (для файлов) и файлы `objects/objects.xlsx` + `objects/objects.json`.
- Если нужно сбросить состояние, удалите `lift_crm.db`, `uploads/` и архивы `archive*.xlsx`, затем запустите сервер заново.
- openpyxl уже добавлен в репозиторий (каталог `vendor/openpyxl`), поэтому приложение стартует даже без установки этой зависимости через `pip`.
